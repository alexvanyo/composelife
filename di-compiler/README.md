# di-compiler

`di-compiler` is a Kotlin compiler plugin that generates top-level context parameter functions for dependency injection, designed to work on top of [Metro](https://github.com/ZacSweers/metro).

## Overview

When using dependency injection with top-level functions, Metro generates an injectable class for any function annotated with `@Inject`. The generated class shares the function's name and provides an `operator fun invoke(...)` method that receives any `@Assisted` parameters while injecting all context and normal dependencies from the Metro dependency graph.

The `di-compiler` plugin complements this by automatically generating matching top-level context functions requiring that generated class as a context parameter, generating overloads for assisted parameters with default values, and preserving annotations such as `@Composable`:

```kotlin
// Input:
@InjectContext
@Inject
@Composable
context(
    _: ChildComponent,
)
fun ParentComponent(
    repository: Repository,
    @Assisted modifier: Modifier = Modifier,
) {
    ChildComponent()
    // ...
}

// Generated by Metro:
@Inject
class ParentComponent(
    private val childComponent: ChildComponent,
    private val repository: Repository,
) {
    @Composable
    operator fun invoke(
        modifier: Modifier = Modifier,
    ) {
        context(childComponent) {
            ParentComponent(
                repository = repository,
                modifier = modifier,
            )
        }
    }
}

// Generated by di-compiler:
context(ctx: ParentComponent)
@Composable
fun ParentComponent(
    modifier: Modifier = Modifier,
) {
    ctx.invoke(
        modifier = modifier,
    )
}

// Overload for assisted parameter with default value:
context(ctx: ParentComponent)
@Composable
fun ParentComponent() {
    ctx.invoke()
}
```

This allows callers to invoke `ParentComponent(...)` directly using standard Kotlin context parameter resolution without needing to manually instantiate or pass dependencies or the Metro-generated `ParentComponent` object:

```kotlin
context(_: ParentComponent)
@Composable
fun GrandparentComponent() {
    ParentComponent()
}
```

While commonly used with Jetpack Compose `@Composable` functions, the mechanism is completely general and supports any top-level function. Any existing annotations on the original function (such as `@Composable`) are preserved on the generated context function.

## Modules

- **`:di-compiler:plugin-annotations`**: Kotlin Multiplatform module providing the `@InjectContext` annotation (`com.alexvanyo.composelife.di.InjectContext`).
- **`:di-compiler:compiler-plugin`**: The Kotlin compiler plugin (supporting Kotlin 2.x K2 frontend and IR backend).
  - **FIR Extension (`InjectContextFirExtension`)**: Discovers functions annotated with `@InjectContext`, generates matching top-level functions with `context(ctx: FunctionName)`, copies assisted parameters, creates overloads for default parameters, and preserves function annotations.
  - **IR Extension (`InjectContextIrTransformer`)**: Generates the function body for each generated declaration, delegating invocation to `ctx.invoke(...)`.

## Setup

To use `di-compiler` in a module:

```kotlin
dependencies {
    implementation(projects.diCompiler.pluginAnnotations)
    kotlinCompilerPluginClasspath(projects.diCompiler.compilerPlugin)
}
```
